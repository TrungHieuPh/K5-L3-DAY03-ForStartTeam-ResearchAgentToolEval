Buoc 1 - Chot y tuong:

Buoc 2 - Tao folder:

Buoc 3 - Viet tool.py:
    File: starter_v0\tools\<ten>\tool.py
    1 ham Python nhan args, tra dict.
    Loi tra {"error": "..."} CHU KHONG raise.

    Vi du khung:
    -----------------------------------------------------------
    def summarize(text: str, max_sentences: int = 3) -> dict:
        if not isinstance(text, str) or not text.strip():
            return {"error": "text must be non-empty string"}
        if max_sentences <= 0:
            return {"error": "max_sentences must be > 0"}
        sentences = text.split(". ")
        summary = ". ".join(sentences[:max_sentences])
        return {"summary": summary}
    -----------------------------------------------------------

    Khung test:

    from tools.summarize.tool import summarize

    def test_summarize_happy_path():
        out = summarize("A. B. C. D.", max_sentences=2)
        assert "summary" in out
        assert out["summary"].count(".") >= 1

    def test_summarize_empty_text_returns_error():
        out = summarize("", max_sentences=2)
        assert "error" in out

    def test_summarize_zero_sentences_returns_error():
        out = summarize("Hello.", max_sentences=0)
        assert "error" in out
